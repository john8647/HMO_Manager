QuickFile Export

Export your financial transactions as a CSV file ready to import into QuickFile for your Self Assessment tax return. Each property is exported separately.

Export Format

The export matches the QuickFile manual import format exactly:

Transaction Date, Transaction Type, Sort Code, Account Number, Transaction Description, Debit Amount, Credit Amount

Each tenant payment is split out by type using your auto-match rules. For example if JIJIN JOSE paid rent and bills in one transfer but you split it during import, the export produces two lines: JIJIN JOSE Rent and JIJIN JOSE Bills.

Expenses for the selected property appear as debit rows with their description as entered.

Each property is exported as a separate file.
Your bank sort code — prefixed with ' in the export.
Included in the export:
  • Credits — tenant rent and bill payments received (bank import and manual cash entries)
  • Debits — expenses recorded against the selected property (water, broadband, insurance, repairs etc.)
  • Retained deposits — where a deposit deduction was applied after move-out (genuine income)
  • Filtered to the selected tax year (6 Apr to 5 Apr)
  • Sorted by date ascending
Not included:
  • Rent charge debits — these are internal accounting entries only, not real bank transactions
  • Advanced Rent offset debits — internal only, created when a deposit is recorded
  • Deposit credits — not income unless retained after move-out (covered above)
  • Unmatched or unconfirmed transactions
  • System-generated entries (source = system)
