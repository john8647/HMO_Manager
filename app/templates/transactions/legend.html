When a bank statement is imported, each row's description is checked against these rules. If a match is found the transaction is automatically assigned to that tenant and their payment is matched against outstanding invoices.

How Auto-Matching Works

1. Pattern matching — The bank description is checked against your patterns case-insensitively. For example the pattern GOLLA H will match any bank row containing those characters.

2. Tenant identification — The pattern identifies who paid. You do not need to set Income Type or Expense Type — leaving them blank is fine. The payment engine automatically looks up the tenant's outstanding invoices and splits the amount into rent and bills portions in the correct order.

3. Preferred Description — This becomes the base for the QuickFile export description. The system appends the type automatically: GOLLA H Rent and GOLLA H Bills as separate lines. If you leave this blank the raw bank description is used instead.

4. Surplus / Deposit — If a payment exceeds all outstanding invoices, the remainder is checked against any pending deposit record. If it matches the deposit amount it is labelled as Deposit. Otherwise it is recorded as Advanced Rent.
